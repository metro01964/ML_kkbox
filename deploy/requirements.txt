# 只會讓建置變慢、映像檔變大。

# ---------------------------------------------------------------------------
# 這份清單是**量出來的，不是讀原始碼推出來的**
# ---------------------------------------------------------------------------
#
# 第一版我用 grep 找 src/serving/*.py 的 import，結論是只需要 fastapi、numpy、
# polars、pydantic、yaml。實際跑起來炸了 —— src/features/__init__.py 會匯入
# encoding.py，而它在模組層級 import sklearn.model_selection。grep 看不到經由
# 套件 __init__.py 傳遞的相依。
#
# 正確的做法是問直譯器：
#
#   before = set(sys.modules); import src.serving.app; after = set(sys.modules)
#
# 這樣量出來多了 sklearn、lightgbm、pyarrow 三個。它們來自 calibrator.py、
# encoding.py、train.py 等六個檔案的模組層級 import，全都是訓練用的東西 ——
# 理論上可以像 candidates.py 那樣改成延遲 import，把映像檔再縮小一些。
#
# 沒有這樣做的理由：實測服務載完模型 + 跑完一次推論的 RSS 是 217 MB，而目標
# 平台（Koyeb / Render 免費方案）給 512 MB。餘裕充足，那個跨六個檔案的重構
# 就是不必要的風險。**先量再決定，不要為了想像中的限制去改已驗證的程式碼。**
